# Тест-план: https://mgtspulse.ru

Разведка: `recon/` — страницы и консоль (`pages.json`), ссылки (`links.json`), API из сети (`api.json`)
и из кода (`api-from-code.json`, 96 маршрутов).

## Карта сайта
| Страница | Кто видит | Формы и интерактив |
|---|---|---|
| `/` главная | все | тема, «Открыть демо», «Войти как …» (4 роли), якоря |
| `/login` | аноним | почта, пароль, кнопки демо-аккаунтов |
| `/register` | аноним | имя, почта, пароль, организация, программа |
| `/invite/{token}` | по ссылке | имя, пароль |
| `/survey/{token}` | по ссылке, без входа | анкета: шкалы, комментарий |
| `/demo/{role}` | демо | вход в песочницу роли |
| `/dashboard` | HR, руководитель | период, подразделения, виджеты, «Настроить», отчёт, тестовый ответ |
| `/pairs`, `?id=&tab=` | HR, руководитель | поиск, фильтры, карточка пары, вкладки, «Объяснить», вердикты, заметки, действия |
| `/program`, `?tab=` | HR | пары, смена наставника, участники, приглашения, итоги потока |
| `/forms`, `?tab=` | HR | рассылка, ответы, ссылки, каналы, автонапоминания, конструктор, источники |
| `/import` | HR | загрузка Excel/Word |
| `/learn`, `?tab=` | все роли | материалы, конструктор, тесты, читалка, прохождение, справочник |
| `/settings` | HR | интеграции, модель, правила, пороги, команда и доступ |
| `/me` | стажёр, наставник | анкета, оценки, Telegram, «Хочу поговорить с HR» |
| шапка | вошедшие | поток, поиск (Ctrl K), тема, уведомления, профиль, выход, ИИ-ассистент |

## Ограничения
- **WebKit** на этой машине не запускается без системных библиотек (`sudo npx playwright install-deps webkit`) — прогоню, если поставишь; иначе только Chromium и Firefox.
- **Письма реальным людям не уходят**: почта не подключена; демо-адреса @pulse.demo письма не получают.
- **Telegram**: тесты не отправляют напоминания в реальные чаты — у новых песочниц нет привязанных чатов.
- **Нагрузка**: каждый вход в демо создаёт песочницу; прогоны ограничу, старые песочницы удаляются сами через 6 часов.
- Генерация теста ИИ (F10) идёт на живой модели — 20–30 секунд на прогон.
