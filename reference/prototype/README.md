# Референс интерфейса

`prototype.dc.html` — исходник кликабельного прототипа «Пульс адаптации». Это эталон внешнего вида, текстов и поведения для `app/web/`.

## Как читать файл
- Внутри `<x-dc>` — разметка всех экранов с инлайн-стилями. Конструкции `<sc-if value="{{...}}">` — условный показ, `<sc-for list="{{...}}" as="x">` — повтор, `{{...}}` — подстановка значения.
- В `<script type="text/x-dc">` — класс `Component`: состояние (`this.state`), демо-данные (`data()`: пары, роли, тексты справочника) и функция `renderVals()`, которая считает всё, что показывает экран: индекс здоровья, сигналы, прогноз, тепловые карты, списки.
- Расчёты в прототипе — демонстрационные. Правильные формулы — в `docs/SPEC.md`, раздел 6.
- Файл не запускается сам по себе: для работы нужен рантайм, которого в репозитории нет. Используй его как исходный код для переноса, не подключай напрямую.

## Как переносить
- Каждый экран → шаблон Jinja2 в `app/web/templates/`, общая шапка и панель — в `base.html`.
- Инлайн-стили → классы в `app/web/static/css/` с переменными:
  - `--bg:#F3F5F9; --ink:#0E1424; --muted:#5B6478; --line:#E3E6EC; --card:#FFFFFF;`
  - `--dark:#070A14; --accent:#0A7CD6; --accent-2:#4F6BDA;`
  - статусы: ok `#1F8F4E`, over `#C26F00`, under `#2F6FDB`, both `#C93434`, words `#6C4FD6`;
  - радиусы карточек 18 px, кнопки-пилюли 999 px.
- Сферы на тёмных блоках — `radial-gradient(circle at 35% 30%, #6F8FE8 0%, #3552B8 32%, #16245C 62%, #070A14 78%)`.
- Графики — SVG, как в прототипе (оси X: `40 + i*98`, Y: `14 + (1-v)*180` в системе 640×230). Без внешних библиотек.
- Логику состояния (вкладки, режим «Настроить», фильтры) переносить на чистый JavaScript в `app/web/static/js/`, данные брать из API.

## Экраны в файле (ориентиры для поиска)
`ГЛАВНАЯ`, `ВХОД`, `ПРИЛОЖЕНИЕ` (верхняя панель), `ДАШБОРД`, `ПАРЫ (список + карточка)`, `ПРОГРАММА (HR)`, `АНКЕТЫ (HR)`, `ОБУЧЕНИЕ`, `НАСТРОЙКИ (HR)`, `МОЯ СТАЖИРОВКА`, `ИИ-ЧАТ`, `ПАЛИТРА КОМАНД`, модальные окна `КУРС`, `ОТЧЁТ`, `ПОГОВОРИТЬ С HR`, `ИТОГИ ВСТРЕЧИ` — это HTML-комментарии в разметке.

## Чего в прототипе нет и нужно добавить
- Экран регистрации HR и экран принятия приглашения — в том же стиле, что вход: слева тёмный блок со сферой, справа форма.
- Экран загрузки «Мы поняли так» по `docs/SPEC.md`, раздел 5: в прототипе есть только упрощённый вариант во вкладке «Источники и загрузка».
