## Расхождения со SPEC (на согласование)
- Сигналы «уровень» и «запаздывание» считаются по паре в целом (среднее по темам), тема с наибольшим разрывом указывается в описании. Запаздывание требует снижения два месяца подряд. Причина — по результатам `ml/validate.py` расчёт по отдельной теме давал 79–92% ложных тревог на здоровых парах при шкалах 1–10 и 1–5; после изменения — 4–12%.
- Добавлен сигнал «Общее падение» (обе стороны снизили оценки ≥ 0,1 с начала программы) — в прототипе это состояние «Оба тревожатся», без него перегруз наставника не виден ни одним из четырёх сигналов.
- Разбор комментариев: модель выбирает уровень тревоги из четырёх («нет / слабая / заметная / сильная»), итог — максимум с тревожностью по словарю; позитивному тексту без тревожных слов модель не может поставить больше 0,3. Причина — `qwen2.5:3b` ставила 0,6 почти любому тексту и давала ложные «слова ≠ цифры».
- ИИ-ассистент: регламент цитируется дословно, частые вопросы о парах отвечаются из данных; модель отвечает на остальное, ответ с числами, которых нет в данных, отбрасывается. Причина — модель 3b выдумывала даты.
