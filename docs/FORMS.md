# Формы и живая цепочка

Любой новый ответ проходит одну цепочку: нормализация → разбор комментария → пересчёт сигналов и индекса → событие SSE `pair_updated` с «было → стало» → дашборд и уведомления HR.

Пересчёт сразу идёт на правилах (быстро, < 1 с). Если включена Ollama, комментарий в фоне разбирает LLM, и при изменении приходит уточнённое событие.

## 1. Своя форма (работает всегда)
- Участник с аккаунтом заполняет анкету в разделе «Моя стажировка» / «Моя пара».
- Без аккаунта — по личной ссылке `/survey/{токен}`: HR берёт ссылки в «Анкеты → Рассылки» или через `GET /api/survey-links`. Ссылка действует 45 дней, открывается с телефона.
- Демо-запасной путь: кнопка «Отправить тестовый ответ» у HR (только при `DEMO_MODE=true`).

## Подключение из интерфейса
Все интеграции подключаются в «Настройки → Интеграции» без перезапуска: HR вводит токен, приложение делает настоящий проверочный запрос к сервису и только после успеха сохраняет настройки организации. Токены не показываются целиком, у каждой интеграции есть журнал событий. Значения из `.env` — запасной вариант для организации, где интеграция не настроена.

- **Яндекс Формы:** OAuth-токен и ID формы. После подключения показан адрес вебхука с секретом организации и кнопка «Загрузить ответы сейчас».
- **Google Forms:** JSON с `client_id`, `client_secret`, `refresh_token` и ID формы.
- **Рабочая почта:** SMTP-сервер, порт (587 — STARTTLS, 465 — SSL), логин, пароль приложения. Письма уходят со ссылкой на анкету; демо-адреса `@pulse.demo` не получают писем.
- **Telegram-бот:** токен от @BotFather. Бот работает через long polling, входящий адрес не нужен. Участник подключает бота личной ссылкой из «Моя стажировка», получает напоминания в чат и может заполнить анкету кнопками; ответ идёт по той же живой цепочке (`source=telegram`).

## Каналы и автонапоминания
«Анкеты → Рассылки»: каналы доставки (почта, Telegram, сайт) и отдельно автонапоминания — дни первого и второго напоминания, сколько раз напоминать, когда сообщить HR, тихие часы и каналы напоминаний. Проверка идёт раз в `REMINDERS_CHECK_MINUTES` минут (по умолчанию 15), кнопка «Проверить и отправить сейчас» запускает её сразу. Итог рассылки честный: по каждому каналу видно, ушло сообщение или почему нет.

## 2. Яндекс Формы через .env
Два способа, можно оба.

**Вебхук (рекомендуется для демо).**
1. В `.env`: `YANDEX_WEBHOOK_SECRET=длинная-случайная-строка`.
2. В форме: «Интеграции» → «Отправить HTTP-запрос» → метод POST, адрес `https://<сервер>/api/forms/yandex/webhook?token=<секрет>`, тело — JSON с ответами (подписи вопросов → значения).
3. В форме обязательно поле с ID участника («Ваш ID», значение вида `С-104`) или рабочей почтой.

**Опрос API (каждые 15 секунд).**
1. Получите OAuth-токен с доступом к Яндекс Формам.
2. В `.env`: `YANDEX_FORMS_TOKEN=...`, `YANDEX_FORM_ID=<id формы>`; при другом адресе API — `YANDEX_FORMS_API`.
3. Перезапустите приложение: опрос стартует автоматически. Обработанные ответы запоминаются и повторно не загружаются.

## 3. Google Forms
1. Создайте OAuth-клиент в Google Cloud, включите Forms API, получите refresh-токен со scope `forms.responses.readonly` и `forms.body.readonly`.
2. В `.env`: `GOOGLE_FORMS_CREDENTIALS={"client_id":"…","client_secret":"…","refresh_token":"…"}`, `GOOGLE_FORM_ID=<id формы>`.
3. Перезапустите приложение. Ответы забираются через `forms.responses.list` каждые 15 секунд.

## Сопоставление полей
Поля формы сопоставляются с вопросами анкеты тем же механизмом, что при загрузке файлов: по коду вопроса (`Q3`) или по похожести формулировки (не ниже 0,6). Длинные текстовые поля и поля «Комментарий» идут в комментарий. Участник определяется по ID или почте.

Без токенов коннекторы выключены, на экране «Настройки» показано «не подключено».
