Составь вопросы теста для стажёра по фрагменту учебного материала «{title}».

Фрагмент:
{content}

Нужно {n} вопроса. Уровень: {difficulty}.
Тип вопросов: {types}

Правила:
- Каждый вопрос — только по фактам из фрагмента. Ничего не выдумывай.
- source — дословная цитата из фрагмента (одно предложение), на которой основан вопрос.
- Неверные варианты правдоподобные: из той же темы, похожей длины, но противоречат фрагменту.
- Не используй варианты «все ответы верны» и «нет верного ответа».
- explanation — почему ответ верный, одно предложение простыми словами.
- Для truefalse: options = ["Верно", "Неверно"], text — утверждение.
- correct — список номеров верных вариантов, начиная с 0.

Верни questions — список объектов: qtype, text, options, correct, explanation, source.
