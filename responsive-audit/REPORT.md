# Адаптивная вёрстка — отчёт

Ветка `feature/responsive`. Проверено в Chromium (Playwright) на 20 экранах × 15 размерах
(320, 360, 375, 390, 414, 430, 768, 820, 1024, 1180, 1280, 1440, 1920, 2560 и альбом 844×390),
плюс 5 всплывающих окон на каждом размере. Аудит до — `AUDIT.md`, `summary-before.txt`;
после — `summary-after.txt`. Пары скриншотов — `report/`.

## Решения по дизайну (согласованы)
- Телефон (< 768px): нижняя панель вкладок вместо обрезанного ряда разделов.
- Кнопка ИИ на телефоне — круглая иконка над панелью, чат на весь экран.
- Таблицы на телефоне — карточки.
- Основной текст на телефоне 16px, подписи не мельче 12px.

### Цифры аудита (до → после)
- Горизонтальный скролл документа: 0 → 0; элементы за краем экрана: 2 (рассылка на 320) → 0.
- Поля ввода < 16px на телефонах: 10 экранов → 0.
- Мелкие тач-цели на 390px: дашборд 48 → 11, настройки 58 → 34, анкеты 48 → 6, обучение 42 → 2.
  Оставшееся — в основном не цели нажатия: подписи `<label>` над полями (само поле 48px),
  переключатели 44×26 с невидимо расширенной областью 44×44, строки-ссылки комментариев высотой 42px.
- Модалки и всплывающие окна: помещаются на всех размерах (и до, и после).

## Что не сделано и почему
- **WebKit/Safari и Samsung Internet** не проверены: WebKit в Playwright на этой машине требует
  системных библиотек (`sudo …/playwright install-deps webkit`), Samsung Internet не эмулируется.
  Firefox запускается; проверки шли в Chromium.
- **Performance 64–68** в Lighthouse mobile — это не вёрстка, а вес JS-отрисовки и тротлинг
  процессора; оптимизация — отдельная задача.
- Мобильная вёрстка сделана поверх существующего desktop-first CSS (медиазапросы `max-width`
  к единым брейкпоинтам), а не переписыванием всего файла mobile-first: полный перенос рискованно
  делать перед защитой. Новые правила собраны в конце `app.css` разделами «адаптивность».

## Как запускать
```bash
# стенд должен быть запущен (make laptop-up), браузер — один раз
uv run --with playwright playwright install chromium

# тесты адаптивности (16 тестов, ~1.5 мин)
E2E_BASE=http://localhost:8000 uv run --with playwright pytest e2e -q

# полный аудит со скриншотами: все размеры или только часть
uv run --with playwright python responsive-audit/audit.py after
uv run --with playwright python responsive-audit/audit.py after 320,375,390
python3 responsive-audit/summarize.py after
```
`e2e/` не входит в обычный `pytest` (в CI нет браузеров).
